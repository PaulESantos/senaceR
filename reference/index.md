# Package index

## API Client & Authentication

Functions for API key management and direct HTTP datastream requests.

- [`senace_set_key()`](https://paulesantos.github.io/senaceR/reference/senace_set_key.md)
  : Set the SENACE API key
- [`senace_api_key()`](https://paulesantos.github.io/senaceR/reference/senace_api_key.md)
  : Retrieve the active SENACE API key
- [`senace_get_data()`](https://paulesantos.github.io/senaceR/reference/senace_get_data.md)
  : Retrieve data from a SENACE datastream
- [`senace_list_datasets()`](https://paulesantos.github.io/senaceR/reference/senace_list_datasets.md)
  : List datasets available from SENACE

## Datastream Helpers

Convenience functions for fetching active SENACE datasets via the REST
API.

- [`senace_cartera_proyectos()`](https://paulesantos.github.io/senaceR/reference/senace_cartera_proyectos.md)
  : Retrieve the Sustainable Investment Project Portfolio
- [`senace_consultoras_ambientales()`](https://paulesantos.github.io/senaceR/reference/senace_consultoras_ambientales.md)
  : Retrieve the Environmental Consulting Firms Register
- [`senace_gastos_especifica()`](https://paulesantos.github.io/senaceR/reference/senace_gastos_especifica.md)
  : Retrieve expenditure by detailed classifier
- [`senace_gastos_fuente()`](https://paulesantos.github.io/senaceR/reference/senace_gastos_fuente.md)
  : Retrieve expenditure by funding source
- [`senace_gastos_generica()`](https://paulesantos.github.io/senaceR/reference/senace_gastos_generica.md)
  : Retrieve expenditure by generic classifier
- [`senace_solicitudes_acceso()`](https://paulesantos.github.io/senaceR/reference/senace_solicitudes_acceso.md)
  : Retrieve public information access requests
- [`senace_visitas()`](https://paulesantos.github.io/senaceR/reference/senace_visitas.md)
  : Retrieve the Institutional Visits Register
- [`senace_reclamos()`](https://paulesantos.github.io/senaceR/reference/senace_reclamos.md)
  : Retrieve the Complaints and Claims Register

# Retrieve the Institutional Visits Register

Downloads records of visits to SENACE offices from the REST API.

## Usage

``` r
senace_visitas(api_key = NULL)
```

## Arguments

- api_key:

  A SENACE API key. If `NULL`, it is retrieved automatically.

## Value

A tibble.

## Examples

``` r
if (FALSE) { # \dontrun{
senace_visitas()
} # }
```

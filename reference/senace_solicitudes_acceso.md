# Retrieve public information access requests

Downloads public information access requests from the REST API.

## Usage

``` r
senace_solicitudes_acceso(api_key = NULL)
```

## Arguments

- api_key:

  A SENACE API key. If `NULL`, it is retrieved automatically.

## Value

A tibble.

## Examples

``` r
if (FALSE) { # \dontrun{
senace_solicitudes_acceso()
} # }
```

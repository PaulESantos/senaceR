# Retrieve the Complaints and Claims Register

Downloads complaints and claims submitted by the public from the REST
API.

## Usage

``` r
senace_reclamos(api_key = NULL)
```

## Arguments

- api_key:

  A SENACE API key. If `NULL`, it is retrieved automatically.

## Value

A tibble.

## Examples

``` r
if (FALSE) { # \dontrun{
senace_reclamos()
} # }
```

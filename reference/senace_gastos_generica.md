# Retrieve expenditure by generic classifier

Downloads budget expenditure by generic classifier from the REST API.

## Usage

``` r
senace_gastos_generica(api_key = NULL)
```

## Arguments

- api_key:

  A SENACE API key. If `NULL`, it is retrieved automatically.

## Value

A tibble.

## Examples

``` r
if (FALSE) { # \dontrun{
senace_gastos_generica()
} # }
```
